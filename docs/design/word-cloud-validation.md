## 保留边界

- 原生 graph 按名称管理选择，同名词条会联动；稳定 id 不解除此限制。
- 字体、数据和几何变化可重排；原生更新过渡路径、主动 emphasis.scale、labelLayout 位移及旋转不保证全程避让。
- rect overlap 模式只对静态排布约束交叠；持续漂浮仅保留容器边界空间。
- 同步布局有候选和空间索引容量限制，整体成本仍随数据量增加。业务应选取适当 TOP 数量，容器不足时不自动压缩显式尺寸。
- 直接消费 option 的应用需在字体就绪后调用 resize。持续动画依赖原生 graph 视图结构，升级 ECharts 时应复跑兼容矩阵。

所有本轮启动的浏览器和预览服务均在结束后按归属复查清理，保留其他任务及用户进程。
