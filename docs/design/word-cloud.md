# 词云软件设计

[整体架构](architecture.md) · [组件 API](../../packages/site/src/components/word-cloud/API.md)

## 目标与方案选择

词云支持水平文字、矩形标签和圆形气泡，组件负责尺寸测量、排布及可选漂浮，业务负责词条筛选、风险含义和外层容器。使用 ECharts 原生 graph 节点与专属布局扩展，不增加独立词云依赖。

| 方案                   | 收益与成本                                                                   | 当前取舍                         |
| ---------------------- | ---------------------------------------------------------------------------- | -------------------------------- |
| graph + 专属布局       | 复用原生标签、分类、图例、状态、命中、事件和更新；需要适配原生视觉时序与坐标 | 当前采用，内部依赖集中在适配模块 |
| custom 全部自绘        | 图元结构完全可控，但要重复承担标签、状态、选择及命中                         | 当前能力不足以抵消重复实现成本   |
| 独立词云扩展或异步布局 | 可发展字形掩码、轮廓填充和后台计算，但增加依赖、取消与过期结果处理           | 出现相应需求和性能证据时重新评估 |

组件扩展 shape、sizeRange、gap、overlap、motion；label、itemStyle、categories、legend 和状态继续使用原生语义，不再创建一套平行样式 API。sizeRange 在三种形态下分别表示字号、建议最小高度和直径，具体默认值由 API 维护。

shape 表示节点形态，不是整个词云的外轮廓。文字／矩形尺寸在线性权重域映射，圆形在最小与最大直径的平方之间插值，使面积随归一化权重变化；存在最小尺寸，因此面积并非原始数值的严格比例。相同非零权重使用 0.5 的归一化位置（圆形按面积取中值），全零取最小尺寸。

## 模块职责与数据流

| 模块                                                                                     | 拥有的知识                                                |
| ---------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| [types.ts](../../packages/plots/word-cloud/src/types.ts)                                 | 对外配置边界与内部系列元数据                              |
| [createWordCloudOption.ts](../../packages/plots/word-cloud/src/createWordCloudOption.ts) | 校验、稳定 id、样式优先级、权重范围和 graph option        |
| [layout.ts](../../packages/plots/word-cloud/src/layout.ts)                               | 无 Vue / ECharts 依赖的尺寸映射、碰撞、空间索引与有限搜索 |
| [wordCloudLayout.ts](../../packages/plots/word-cloud/src/wordCloudLayout.ts)             | 字体测量、状态外扩、原生视觉时序、view 坐标换算和缓存     |
| [motion.ts](../../packages/plots/word-cloud/src/motion.ts)                               | 最大位移包络、稳定轨迹、动画与环境监听的生命周期          |
| [selection.ts](../../packages/plots/word-cloud/src/selection.ts)                         | 显式 selected 与用户选择的协调、跨重建恢复                |
| [WordCloud.ts](../../packages/plots/word-cloud/src/WordCloud.ts)                         | 公共渲染、主题、字体完成事件与实例绑定                    |
| [组件入口](../../packages/plots/word-cloud/index.ts)                                     | 注册 GraphChart、标签布局、专属布局与动画扩展             |

输入先生成 graph 数据与内部设置，再在原生视觉与布局阶段完成测量、尺寸和位置计算，最后由 GraphView 绘制。持续漂浮在 post-update 阶段绑定，不参与静态放置求解。原生内部知识不进入纯算法或通用 shared，调用方不传布局坐标，也不需要维护第二份交互状态。

分类视觉阶段可能用未定义的分类尺寸覆盖外层 symbolSize 回调结果，适配器先保存原生已求值的尺寸，后续按 rawIndex 读取，避免重新调用业务回调。专属布局在原生视觉就绪后完成像素几何，再通过 view 坐标系的 pointToData 写回节点布局；不能把像素坐标直接当成 graph 数据坐标。

## 数据身份与选项边界

name 必须非空，value 必须是有限非负数，0 有效。非法词条跳过绘制但保留原始数据索引，回调仍接收标量 value 和业务字段；源对象及数组顺序不变。重复显式 id 使生成系列无效；没有 id 时按名称和同名序号生成，频繁重排的输入应提供稳定 id。

样式按系列、分类、数据项解析，数据项优先。显式原生 symbolSize 覆盖默认背景尺寸，但 text 字号仍由 label / sizeRange 决定。circle 只接受等宽高尺寸。非法布局清空生成系列，非法单项尺寸跳过相应节点，非法 motion 只关闭漂浮；诊断保持组件前缀和可定位字段。

显式 series 整体替换生成内容。createWordCloudOption 返回的是需要专属扩展的 graph option，不是新注册的原生 wordCloud 系列；直接消费者仍需加载同一入口完成注册。内部 __ixWordCloud 标记不属于稳定扩展 API。

## 测量与确定性布局

测量使用 ECharts 的文字能力，包含 formatter 最终文案、字体、富文本、换行、省略、padding、标签偏移，以及显式状态标签的最大外扩。默认关闭 emphasis.scale，状态变化只改变绘制，不能临时重排来弥补没有预留的尺寸。formatter 应保持纯函数，不承诺调用次数。

自动标签宽度先测自然宽度再限制最大值，避免把短名称也扩成整条上限宽度。矩形使用保留宽高比的自定义 path 和方形 symbol 缩放，使描边厚度与像素圆角稳定；itemStyle.borderRadius 的支持由适配器补充，不能误当成原生 graph 自带的圆角能力。文字形态在调色板视觉完成后补 emphasis 的默认提亮与不透明标签，显式状态标签仍优先。

字体测量按系列模型缓存，包含几何与字体版本信息且限制容量；字体完成事件使缓存失效并 resize。直接 option 消费者自行在字体就绪后 resize。相同数据、尺寸和字体环境得到相同布局，不承诺不同系统字体的逐像素一致。

放置顺序按权重、碰撞面积及稳定 id 决定。文字与矩形从中心向外搜索；圆形先在已放置节点周围尝试相切距离的候选，再以螺旋搜索补充。空间网格减少附近碰撞比较，异常大边界回退扫描；候选与网格枚举都有边界，避免极大有限数导致无界循环或分配。

不重叠模式避让完整背景、文字和状态外扩。矩形 overlap 模式允许背景交叠并可遮挡文字，但静态布局限制最小交叠宽高、面积比例和邻居数量，拒绝贴边与不足间距；规则由纯碰撞函数集中维护，具体数值见 API。

放不下的节点以非有限布局坐标排除绘制和命中，保留数据身份，不使用透明可点击图元代替隐藏，也不悄悄缩小显式字号或尺寸。隐藏／零尺寸容器不启动无意义搜索。数据量仍决定同步 CPU 和内存成本，有界搜索不等于恒定耗时，业务应预选适当 TOP 数量。

## 更新与选择状态

数据、权重、分类筛选、容器或文字几何变化可以重排；仅改变非几何样式的颜色、透明度、搜索高亮和普通选择时保持位置。图例筛选重排可见节点，但使用完整有效数据的权重范围，避免同一词条因筛选突然改变大小。原生更新过渡路径不保证全程无交叉。

组件使用公共数据合并，同时启用 resetOnDataIdentityChange。id、name 或显式 selected 快照变化时重建 option，清除原生选择索引缓存；普通权重更新继续合并。身份变化可能牺牲连续过渡，换取正确索引和选择语义，不修改 ECharts 私有选择缓存。

selection 按稳定 id 记忆用户选择，调用方显式 selected 变化接管状态，删除项清理记忆，主题重建后重新绑定实例并恢复。原生 graph 按名称管理选择，同名词条仍会联动，稳定 id 不解除这一限制。

## 漂浮与资源生命周期

漂浮围绕静态布局位置进行，id 决定方向、相位和周期，权重调低大词条的幅度，amplitudeRatio 归一化后分配横纵位移。最大位移契约同时用于布局留位和动画生成；新轨迹不得在未修改留位策略时超过该包络。

不重叠时预留完整运动包络；矩形 overlap 模式只为容器边缘预留运动空间，节点间静态交叠规则不约束持续运动。文字、背景和命中区域同步移动，不改变字号与分类颜色。

motion 只控制持续漂浮，animation: false 为总开关。默认悬停词条时暂停，loading 和页面隐藏时暂停，系统减少动态效果时停止循环，SSR 不启动持续动画。过滤节点停止其循环，恢复后重新绑定；环境切换不能丢失过滤状态。

动画通过 graph Symbol 首个子路径的偏移实现，按最终变换把像素振幅换算到局部坐标；父节点位置、缩放和状态仍归原生 graph 管理。轨迹签名与动画仍有效时复用循环，被中止的二维轨迹可根据当前偏移恢复相位；单轴退化轨迹重新使用稳定初相位，不承诺所有配置变更都无缝续播。ZRender Animator 循环与原生入场及位置更新分开；view remove / dispose 清理循环，dispose 释放环境监听，Vue 卸载释放字体监听。

## 支持边界与演进条件

当前使用包围盒／圆形避让，不做字形像素穿插、任意轮廓或图片掩码。不支持内置图布局上的连线、force、拖拽、漫游、轴、dataZoom、dataset / encode；visualMap 不作为稳定配置契约。主动 emphasis 缩放、旋转和 labelLayout 二次位移超出默认避让保证。

升级 ECharts 时重点检查视觉阶段顺序、GraphView 坐标、Symbol 子路径、状态及 remove / dispose。结构变化只在适配边界修正，不能把私有字段暴露给业务。

新增 shape 要同时补尺寸、测量、碰撞、命中和契约测试。只有真实大数据卡顿证据才引入可取消异步布局；任意轮廓需求则重新评估承载方案。词云特有的交叠规则不提前抽为全局布局框架。
