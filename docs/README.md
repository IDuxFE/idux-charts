# 文档导航

[软件设计](design/README.md)面向维护者，解释当前实现的职责、关键取舍和修改约束。先阅读[整体架构](design/architecture.md)，再按组件进入设计说明；Line 与 Area 共用一份设计。

属性、类型、配置示例与实际演示见[站点组件 API 和 demos](../packages/site/src/components)。

设计文档随实现更新，不保存初稿、逐轮审查和实施日记。测试批次、覆盖率结果、截图和构建日志由对应 PR 与 CI 承载；设计文档只记录长期验证要求。

站点原有 `Design.md` 仅保留“设计指南”页签元数据，正文暂为空，供后续内容使用。
