# 图表性能基线

[English](PERFORMANCE.md) | 简体中文

先通过 `pnpm exec playwright install chromium` 安装 Chromium，再运行 `pnpm benchmark:charts`。

基准脚本构建生产环境 fixture，在无头 Chromium 中使用 SVG 渲染器，关闭动画，渲染 960 × 480 px 的图表。两种负载均使用三个系列，初始显示类目轴最后 25% 的数据。条纹堆叠面积图包含一个具有单点缺失和连续缺失的系列。每轮依次挂载图表、替换系列值、派发缩放操作；输入数据生成不计入耗时。测量包括 Vue 更新和两个动画帧，因此在 60 Hz 下，即使更新能在帧预算内完成，测得的耗时通常也在 33 ms 左右。脚本丢弃一次预热结果，对每种负载的 24 次测量报告 p50 和 p95。

以下参考结果采集于 2026-11-12，环境为 Chromium 156.0.8078.4、macOS 15.8.3、Intel Core i5-9600K。点数指每个系列的点数，单位为毫秒，格式为 p50 / p95。

| 负载                 |   点数 |          首帧 |        刷新 |        缩放 |
| -------------------- | -----: | ------------: | ----------: | ----------: |
| 折线图               |  1,000 |   33.1 / 34.5 | 32.9 / 34.6 | 33.0 / 34.1 |
| 含缺失值的堆叠面积图 |  1,000 |   33.4 / 35.3 | 33.3 / 35.3 | 33.5 / 35.3 |
| 折线图               | 10,000 |   66.6 / 83.0 | 49.0 / 50.5 | 33.8 / 34.3 |
| 含缺失值的堆叠面积图 | 10,000 | 100.0 / 115.1 | 50.2 / 66.3 | 32.9 / 34.4 |

请在同一台机器、相同浏览器和相近系统负载下比较结果。先通过重复运行确认尾部延迟的变化，再判断是否由代码变更引起。
